# 📊 Excel Sales Analytics Dashboard

### Interactive Sales Performance Analysis | Microsoft Excel

## Project Overview

Developed an interactive Sales Analytics Dashboard using Microsoft Excel to analyze sales revenue, product performance, salesperson productivity, and geographical sales trends.

The project transforms transactional sales data into meaningful business insights through KPI reporting, Pivot Tables, Pivot Charts, interactive slicers, and timeline filters.

The dashboard is designed to support data-driven decision-making by presenting key sales metrics in a clear and interactive format.

## Dashboard Features

**Sales Overview**

Provides an overview of revenue, transaction volume, sales trends, product contributions, and location-based sales performance.

**Product Analysis**

Analyzes product-level performance using sales quantities, revenue comparisons, and Top 3 and Bottom 3 rankings.

**Salesperson Performance**

Evaluates individual salesperson performance through comparative charts and performance rankings.

**Interactive Filtering**

Uses slicers and timeline controls to explore sales performance by product, location, and date.

**Dashboard Navigation**

Includes interconnected Dashboard, Products, Salespeople, and About sections for convenient navigation.

## Key Business Insights

- **Laptops** generated the highest revenue, contributing ₹4,87,11,017.
- **4K LED TVs** generated ₹4,68,30,474, making them another major revenue contributor.
- The dashboard enables comparisons across products, locations, salespeople, and reporting periods to identify strong and weak performance areas.
- Interactive KPI cards allow users to monitor performance for selected business segments.
